# ClapDesk

**박수 몇 번이면 펼쳐지는 내 작업 환경.**

마이크로 박수 소리를 감지해서, 미리 등록해 둔 프로그램들을 한 번에 실행해 주는 Windows 데스크톱 유틸리티입니다.
**몇 번 치느냐에 따라 다른 묶음(프리셋)이 켜집니다** — 2번은 일, 3번은 취미처럼요.
재미로 만드는 개인 프로젝트지만, "매일 아침 똑같은 앱 8개 켜기"라는 진짜 귀찮음을 해결하는 게 목적입니다.

<br clear="left">

> 이름의 뜻: **Clap**(박수) + **Desk**(책상) — 박수 한 번으로 내 책상을 펼친다는 뜻입니다.

```
    짝 짝           →   VSCode + Chrome + Slack ...      (2번 = 일)
    짝 짝 짝        →   Steam + Discord + Spotify ...    (3번 = 취미)
    짝 짝 짝 짝     →   유튜브 + 캘린더 ...              (4번 = 휴식)
```

## 어떻게 동작하나요

**핵심: 하루 종일 듣지 않습니다.** 필요한 순간에만 잠깐 듣습니다.

```
💤 대기 중          마이크를 아예 열지 않습니다 (트레이 아이콘 = 회색)
    │
    │  ← 화면 잠금을 풀거나, [🎧 듣기 시작]을 누르면
    ▼
🎧 듣는 중 (5분)    박수를 기다립니다 (트레이 아이콘 = 초록)
    │
    │  ← 짝짝! 또는 시간 초과
    ▼
💤 대기 중          프로그램을 실행하고 다시 마이크를 놓습니다
```

1. **화면 잠금을 풀면** 자동으로 듣기 시작합니다. (자리에 돌아와 일을 시작하는 순간)
2. 소리가 나면 **"그게 박수인지"** 를 5가지 특징으로 따집니다.
   음정이 있으면 기침·말소리, 저음이면 문 닫는 소리, 길게 이어지면 종이 소리로 걸러냅니다.
3. 박수를 **0.15초~0.8초 간격으로 이어서** 치면 개수를 셉니다.
   마지막 박수 후 0.8초쯤 조용해지면 "다 쳤다"고 보고 **그 개수에 맞는 묶음**을 실행합니다.
4. 실행 직전 **3초간 [실행 취소]** 버튼이 뜹니다. 개수를 잘못 세었다면 되돌릴 수 있습니다.
5. 실행 후 **곧바로 마이크를 놓습니다.** 5분 안에 박수가 없어도 마찬가지입니다.

> ⏱️ **왜 두 번째 박수에서 바로 켜지지 않나요?**
> 세 번째 박수가 올지 알 수 없기 때문입니다. 2번에서 곧바로 발동해 버리면 3번을
> 칠 기회가 영영 없어집니다. 그래서 **조용해질 때까지 기다렸다가** 개수를 확정합니다.
> 대가는 마지막 박수 후 약 0.9초의 지연이고, 얻는 것은 2~5번을 한 방식으로 다루는 일관성입니다.

> 🎯 **왜 이렇게 만들었나요?**
> 감지가 아무리 정확해도 **하루 8시간을 듣고 있으면 오탐은 언젠가 납니다.** 확률 싸움입니다.
> 듣는 시간을 8시간에서 5분으로 줄이면 그 확률도 그만큼 줄어듭니다.
> 덤으로 평소에는 마이크를 아예 잡지 않으니 화상회의와 충돌하지도 않습니다.

> 🎯 **판정은 크기(음량)로 하지 않습니다.** 전부 소리의 '모양'(비율)으로 합니다.
> 그래서 **리미터·클리핑 가드가 걸린 마이크**(Elgato Wave Link, 오디오 인터페이스 등)에서도
> 동작합니다. 이유는 [docs/DETECTION.md](docs/DETECTION.md)에 정리했습니다.

## 빠른 시작 — 그냥 쓰고 싶다면

**파이썬을 깔 필요가 없습니다.** 파이썬·필요한 라이브러리·오디오 드라이버가 전부
프로그램 안에 들어 있습니다.

| 방식 | 파일 | 이럴 때 |
|------|------|---------|
| **설치본** | `ClapDesk-Setup-1.0.0.exe` (23MB) | 계속 쓸 PC에. 시작 메뉴 바로가기·제거 프로그램·자동 실행 설정이 함께 |
| **단일 파일** | `ClapDesk.exe` (31MB) | 설치 없이. USB에 넣어 들고 다니기 |

1. 둘 중 하나를 실행
2. 마이크를 고르고 → `[≡ 프로그램 설정]` 에서 실행할 프로그램 등록
3. 끝. 창을 닫아도 트레이에서 계속 돕니다

> 설정은 **프로그램 옆의 `config/apps.yaml`** 에 저장됩니다.
> 설치본은 관리자 권한 없이 사용자 폴더에 설치하므로 이 파일을 그대로 쓸 수 있습니다.
> (쓰기가 막힌 위치라면 `%LOCALAPPDATA%\ClapDesk\` 로 물러섭니다)

> 💡 **단일 파일은 실행할 때마다 31MB를 임시 폴더에 풀기 때문에 첫 실행이 1~2초 느립니다.**
> 설치본은 폴더 형태라 즉시 뜹니다. 자동 실행으로 쓸 거라면 설치본이 낫습니다.

### 직접 만들기

```powershell
pip install pyinstaller
python tools/build_exe.py              # → dist/ClapDesk.exe (단일 파일)

winget install JRSoftware.InnoSetup    # 설치본을 만들려면 (처음 한 번만)
python tools/build_installer.py        # → dist/ClapDesk-Setup-1.0.0.exe
```

빌드 옵션은 `tools/build_exe.py` 안에 **왜 필요한지와 함께** 적어 뒀습니다.
옵션 하나가 빠지면 "내 PC에서는 되는데 남의 PC에서는 안 되는" exe가 나오는데,
그런 문제는 원인을 찾기가 정말 어렵기 때문입니다.

> 🔍 **exe 에서도 진단 명령이 그대로 됩니다.** 창 없는 앱이라 원래는 출력이 사라지지만,
> 터미널에서 실행하면 그 콘솔에 붙어서 결과를 보여줍니다.
> ```powershell
> .\ClapDesk.exe --check-config    # 설정이 올바른지
> .\ClapDesk.exe --list-devices    # 마이크가 잡히는지
> ```

## 소스로 실행하기 (개발)

```powershell
# 1. 가상환경
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. 설치 (-e 는 코드를 고치면 바로 반영되는 개발 모드)
#    패키지가 src/ 아래에 있어서 이 과정을 거쳐야 `python -m` 으로 실행됩니다.
pip install -e .

# 3. 실행 (창이 뜹니다)
python -m clap_launcher
```

**실행할 프로그램은 창 안에서 등록하면 됩니다.** `[프로그램 설정]` 버튼을 누르고
`추가` → `찾아보기` 로 exe를 고르면 끝입니다. 설정 파일을 직접 열 필요가 없습니다.

<details>

```powershell
copy config\apps.example.yaml config\apps.yaml   # 예시를 복사해서 경로를 고치기

```

경로 오타는 박수를 백 번 쳐도 안 켜지는 원인 1위입니다. `--launch-apps` 로 미리
실행해 보면 어떤 항목이 왜 실패하는지 몇 초 만에 알 수 있습니다.

### 화면

**뉴모피즘(Neumorphism)** 테마입니다. 배경과 같은 색의 요소가 그림자만으로 튀어나오거나
움푹 들어가 보입니다. 아이콘은 이모지가 아니라 **선으로 직접 그려서** 글꼴 환경에 상관없이
항상 같은 모양·색으로 나옵니다.

```
   ClapDesk
   ◟ 듣는 중  ·  4:58 남음
   박수를 기다리는 중… (2~5번, 친 횟수에 따라 다른 묶음)

   ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁     -75.3 dBFS   ← 움푹 들어간 홈 안의 막대

   ●━━  화면 잠금을 풀면 자동으로 듣기 시작
   ━━○  Windows 시작할 때 자동 실행 (트레이에서 조용히 시작)
   듣는 시간  (1분) (3분) [5분] (10분) (무제한)   ← 고른 것만 눌려 있다

   ( ■ 듣기 중지 )  ( ≡ 프로그램 설정 )
   ( ◎ 박수 보정 )  ( ♪ 마이크 변경 )
   2번 일: VS Code, 업무 브라우저 외 1개  ·  3번 취미: Steam
```

맨 아랫줄은 **어느 횟수에 무엇이 켜지는지**를 보여줍니다. 프리셋이 넷이면
"2번이 뭐였더라"를 기억하기 어려우니 화면이 대신 기억해 줍니다.

박수를 치면 같은 자리가 **취소 배너**로 바뀌고, 3초 뒤에 실행됩니다.

```
   ◔ '취미' 실행 대기 중
   박수 3번으로 인식했습니다.
   ...
   박수 3번 → '취미' 2개를 3초 뒤 실행합니다.        ( × 실행 취소 )
```

3초가 지나면 결과가 표시됩니다.

```
   성공 3개                                    ← 전부 켜졌을 때
   성공 2개 / 실패 1개 — Slack: 경로를 찾을 수 없습니다: C:\...\slack.exe
```

> 실패해도 **나머지는 그대로 켜집니다.** 경로 오타 하나 때문에 아침 준비가 통째로
> 날아가면 안 되니까요. 실패한 항목은 이름과 이유를 함께 보여주므로 어디를 고칠지 바로 압니다.

### 실행할 프로그램 등록하기

메인 화면의 `[≡ 프로그램 설정]` 버튼을 누르면 나오는 화면입니다.

```
   ≡ 박수 횟수별 실행 목록
   박수 횟수를 고르고, 그때 켤 프로그램을 위에서 아래 순서로 등록하세요.

   [2번 · 일] (3번 · 취미) (4번 · 휴식) (5번 · 비어 있음)   ← 눌린 탭이 지금 고치는 묶음
   이 묶음의 이름 (예: 일 · 취미 · 휴식)  [ 일        ]

   ┌──────────────────────────────────────────┐
   │ ○ VS Code       [프로그램]  C:/…/Code.exe │  ← 고르면 아래 칸에 내용이 뜬다
   │ ○ 업무 브라우저  [프로그램]  C:/…/chrome.exe│
   │ × Spotify       [프로그램]  C:/…/Spotify  │  ← × 는 잠시 꺼둔 항목
   └──────────────────────────────────────────┘
   ( + 추가 ) ( 🗑 삭제 ) ( ↑ ) ( ↓ ) ( ✓ 켜기/끄기 )

   이름   [ VS Code                       ]
   종류   [프로그램] (웹주소) (폴더) (스토어)
   경로   [ C:/…/Code.exe        ] ( 📁 찾아보기 )
   실행 인자 [ F:/dev                     ]
   대기(초)  [ 1.0 ]

   ( ✓ 저장하고 돌아가기 )  ( × 취소 )
```

- **맨 위 탭이 박수 횟수**입니다. 탭마다 목록이 따로 있고, 탭 이름은 그 묶음의 이름입니다.
  아직 아무것도 안 넣은 탭은 `비어 있음` 으로 보입니다 (그 횟수로 쳐도 아무 일도 안 납니다).
- **`찾아보기`** 로 exe나 폴더를 직접 고를 수 있습니다 (경로 오타가 나지 않습니다).
- **`↑ ↓`** 로 실행 순서를 바꿉니다. 목록 순서가 곧 실행 순서입니다.
- **`켜기/끄기`** 는 지우지 않고 잠시 빼두는 기능입니다 (`enabled: false`).
- **`대기(초)`** 는 이 항목을 켠 뒤 다음 항목까지 쉬는 시간입니다.
  무거운 프로그램 뒤에 1~2초를 주면 PC가 덜 버벅입니다.

> ⚠️ **저장하면 `config/apps.yaml` 을 다시 씁니다.** 그 파일에 직접 적어둔 주석은
> 사라집니다. 대신 **직전 내용이 `apps.yaml.bak` 으로 남으니** 되돌릴 수 있습니다.
> 설정 파일을 손으로만 관리하고 싶다면 이 화면에서 저장하지 마세요.
> (감지 기준값·마이크 설정은 이 화면에서 저장해도 그대로 보존됩니다)

### 트레이에 상주하기 · 자동 시작

**창을 닫아도 종료되지 않고 트레이로 내려갑니다.** 잠금을 풀 때 알아서 켜지는 게 이
프로그램의 쓸모인데, 창을 닫았다고 죽어버리면 그 쓸모가 사라지기 때문입니다.

```
트레이 아이콘  🟢 초록 = 듣는 중 (마이크를 열고 있음)
              ⚪ 회색 = 대기 중 (마이크를 아예 잡지 않음)

우클릭 메뉴    창 열기  /  듣기 시작·중지  /  종료
```

- **완전히 끄려면** 트레이 아이콘 → `종료` 를 누르세요. (창의 X는 숨기기입니다)
- 메인 화면의 **`Windows 시작할 때 자동 실행`** 을 켜면 로그인할 때 트레이에서 조용히
  시작합니다. 창은 뜨지 않습니다.
- 트레이를 쓸 수 없는 환경(pystray 미설치·일부 원격 세션)에서는 **창을 닫으면 그냥 종료**됩니다.
  기능이 하나 빠질 뿐 프로그램은 정상 동작합니다.

### 이미 켜져 있는 프로그램은 다시 켜지 않습니다

아침에 박수로 8개를 켰는데 점심 먹고 와서 또 치면 VS Code 창이 하나 더 뜨겠죠.
그래서 **이미 실행 중인 프로그램은 건너뜁니다.**

```
성공 2개 / 이미 켜져 있음 3개 / 꺼둔 항목 1개
```

- 실행파일(`exe`)만 검사합니다. 웹 주소는 탭을 하나 더 여는 게 자연스럽고,
  스토어 앱은 실행파일 이름을 알 수 없기 때문입니다.
- 브라우저처럼 **창을 하나 더 띄우고 싶다면** `apps.yaml` 에서 그 항목만
  `skip_if_running: false` 로 두세요.

### 첫 실행 — 마이크 고르기

처음 실행하면 **마이크 선택 화면**이 먼저 나옵니다.

```
┌─────────────────────────────────────────┐
│  🎤 사용할 마이크를 고르세요             │
│  목록에서 마이크를 고른 뒤 박수를 쳐보세요│
│  아래 막대가 크게 튀는 마이크가 정답입니다│
│ ┌─────────────────────────────────────┐ │
│ │ [  0] Microsoft 사운드 매퍼 (MME)   │ │
│ │ [  3] Mic In(Elgato Wave:1) (MME)   │ │
│ │ [  6] 마이크(Logitech StreamCam)    │ │
│ └─────────────────────────────────────┘ │
│  ▮▮▮▮▮▮▮▮▮▮▯▯▯▯▯▯▯▯   -35.1 dBFS       │
│  ✅ 소리가 잘 잡힙니다                   │
│                      [이 마이크 사용하기]│
└─────────────────────────────────────────┘
```

목록에서 마이크를 고르면 **그 자리에서 바로 막대가 움직입니다.** 박수를 쳐보고 크게 튀는
장치를 고르면 됩니다. 소리가 확실히 잡힌 마이크만 `이 마이크 사용하기` 버튼이 열립니다.

> 왜 이 화면이 먼저 나오나요? 이 PC에서 확인해 보니 입력 장치가 **29개**나 잡혔고,
> Windows 기본 장치가 실제 마이크가 아니라 **가상 오디오 장치**로 잡혀 있었습니다.
> "박수를 쳐도 반응이 없다"의 대부분이 여기서 갈립니다.

고른 마이크는 `%LOCALAPPDATA%\ClapDesk\settings.json`에 저장되고, 다음부터는 바로
메인 화면이 나옵니다. 바꾸고 싶으면 메인 화면의 `🎤 마이크 변경` 버튼을 누르세요.

### 콘솔에서 확인하기 (디버깅용)

```powershell
python -m clap_launcher --list-devices   # 마이크 목록
python -m clap_launcher --level          # 콘솔 음량 미터
python -m clap_launcher --level --device 3
python -m clap_launcher --reset-setup    # 마이크 선택 초기화
python -m clap_launcher --check-config   # 설정 파일 검사 (실행은 안 함)
python -m clap_launcher --launch-apps    # 박수 없이 2번 묶음을 지금 실행해 보기
python -m clap_launcher --launch-apps --claps 3   # 3번 묶음을 실행해 보기
```

```
🎤 입력 장치: [3] Mic In(Elgato Wave:1) (16000Hz, 모노, 160샘플/조각)
[█████████████████·······················]   -35.1 dBFS  최고  -35.1
```

> ⚠️ `config/apps.yaml`은 **기기마다 프로그램 설치 경로가 다르므로 git에 올리지 않습니다.**
> 다른 PC에서 쓸 때는 `apps.example.yaml`을 다시 복사해서 그 기기에 맞게 경로를 채워야 합니다.

### 아이콘

앱 아이콘은 **코드로 그립니다** (`tools/make_icon.py`). 테마 색이 바뀌면 다시 돌리기만 하면 되고,
화면 안에서 쓰는 박수 마크와 같은 도형을 그대로 씁니다.

```powershell
python tools/make_icon.py     # assets/icon.ico, icon.png, icon_preview.png 를 다시 만듭니다
```

- `assets/icon.ico` — exe·창·작업표시줄용. 16~256px 을 한 파일에 담습니다
  (작은 크기를 빼면 작업표시줄에서 흐려집니다)
- 트레이 아이콘은 같은 배지를 **상태 색으로** 칠해서 씁니다 (초록=듣는 중, 회색=대기 중)
