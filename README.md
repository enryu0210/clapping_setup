# 👏 Clapping Setup

**박수 두 번(짝짝)이면 일할 준비 끝.**

마이크로 박수 소리를 감지해서, 미리 등록해 둔 업무용 프로그램들을 한 번에 실행해 주는 Windows 데스크톱 유틸리티입니다.
재미로 만드는 개인 프로젝트지만, "매일 아침 똑같은 앱 8개 켜기"라는 진짜 귀찮음을 해결하는 게 목적입니다.

```
    짝    짝
     👏 👏      →   VSCode + Chrome + Slack + Spotify ... 동시 실행
```

## 어떻게 동작하나요

1. 프로그램이 마이크를 계속 듣습니다. (녹음은 **저장하지 않습니다.** 메모리에서만 분석)
2. 소리가 나면 **"그게 박수인지"** 를 5가지 특징으로 따집니다.
   음정이 있으면 기침·말소리, 저음이면 문 닫는 소리, 길게 이어지면 종이 소리로 걸러냅니다.
3. 박수가 **0.15초~0.8초 간격으로 두 번** 들리면 발동합니다.
4. `config/apps.yaml`에 적어둔 프로그램들을 순서대로 실행합니다.

> 🎯 **크기(음량)로 판단하지 않습니다.** 전부 소리의 '모양'(비율)으로 판단합니다.
> 그래서 **리미터·클리핑 가드가 걸린 마이크**(Elgato Wave Link, 오디오 인터페이스 등)에서도
> 동작합니다. 이유는 [docs/DETECTION.md](docs/DETECTION.md)에 정리했습니다.

## 빠른 시작 (구현 완료 후 기준)

```powershell
# 1. 가상환경
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. 설치 (-e 는 코드를 고치면 바로 반영되는 개발 모드)
#    패키지가 src/ 아래에 있어서 이 과정을 거쳐야 `python -m` 으로 실행됩니다.
pip install -e .

# 3. 내 설정 파일 만들기 (예시 파일 복사)
copy config\apps.example.yaml config\apps.yaml

# 4. 실행 (창이 뜹니다)
python -m clap_launcher
```

### 첫 실행 — 마이크 고르기

처음 실행하면 **마이크 선택 화면**이 먼저 나옵니다.

```
┌─────────────────────────────────────────┐
│  🎤 사용할 마이크를 고르세요             │
│  목록에서 마이크를 고른 뒤 박수를 쳐보세요│
│  아래 막대가 크게 튀는 마이크가 정답입니다│
│ ┌─────────────────────────────────────┐ │
│ │ [  0] Microsoft 사운드 매퍼 (MME)   │ │
│ │ [  3] Mic In(Elgato Wave:1) (MME)   │ │
│ │ [  6] 마이크(Logitech StreamCam)    │ │
│ └─────────────────────────────────────┘ │
│  ▮▮▮▮▮▮▮▮▮▮▯▯▯▯▯▯▯▯   -35.1 dBFS       │
│  ✅ 소리가 잘 잡힙니다                   │
│                      [이 마이크 사용하기]│
└─────────────────────────────────────────┘
```

목록에서 마이크를 고르면 **그 자리에서 바로 막대가 움직입니다.** 박수를 쳐보고 크게 튀는
장치를 고르면 됩니다. 소리가 확실히 잡힌 마이크만 `이 마이크 사용하기` 버튼이 열립니다.

> 왜 이 화면이 먼저 나오나요? 이 PC에서 확인해 보니 입력 장치가 **29개**나 잡혔고,
> Windows 기본 장치가 실제 마이크가 아니라 **가상 오디오 장치**로 잡혀 있었습니다.
> "박수를 쳐도 반응이 없다"의 대부분이 여기서 갈립니다.

고른 마이크는 `%LOCALAPPDATA%\ClappingSetup\settings.json`에 저장되고, 다음부터는 바로
메인 화면이 나옵니다. 바꾸고 싶으면 메인 화면의 `🎤 마이크 변경` 버튼을 누르세요.

### 콘솔에서 확인하기 (디버깅용)

```powershell
python -m clap_launcher --list-devices   # 마이크 목록
python -m clap_launcher --level          # 콘솔 음량 미터
python -m clap_launcher --level --device 3
python -m clap_launcher --reset-setup    # 마이크 선택 초기화
```

```
🎤 입력 장치: [3] Mic In(Elgato Wave:1) (16000Hz, 모노, 160샘플/조각)
[█████████████████·······················]   -35.1 dBFS  최고  -35.1
```

> ⚠️ `config/apps.yaml`은 **기기마다 프로그램 설치 경로가 다르므로 git에 올리지 않습니다.**
> 다른 PC에서 쓸 때는 `apps.example.yaml`을 다시 복사해서 그 기기에 맞게 경로를 채워야 합니다.
